The repository started without `ledger/submissions.csv` or `ledger/raw_paste.txt`. Before choosing `PRUNE,p2p6`, the agent checked the available main ledgers in sibling repositories GEMSDOE84–88 and active PRUNE PR descriptions in GEMSDOE84, GEMSDOE85, and GEMSDOE88. Active PR #29 in GEMSDOE88 was found to contain p3.2/p3.7/p4.3; this history is described in `IRREGULARITIES.md`. This is not a claim that every historical experiment in every sibling repository has been imported here. Check all current main/active PR records before a future build.

All competition inputs and submission TIFF/ZIP artifacts are excluded from Git. Local release receipts contain SHA-256s and validation facts; the TIFFs remain local and gitignored. Data-use terms for public sibling mirrors are unchecked; see the manifest and `IRREGULARITIES.md`.
