## Predeclared experiment: Hurst-like roughness-regime break

- **Only candidate:** `hurst_break` from B12. The code accepts only B12, B19 control, and the footprint; it has no catalogue/label argument.
- **Fixed scales:** semivariogram lags 1, 2, and 4 grid pixels (100/200/400 m) in the 100 m EPSG:32611 grid; for each lag, average valid horizontal and vertical squared increments in an 11×11-pixel window, requiring at least 50% valid pairs per direction. The effective exponent is half the least-squares slope of `log(gamma(h))` against `log(h)`; the candidate is the local Gaussian-gradient magnitude of that exponent (sigma 2 pixels). The footprint edge is eroded by a fixed 8 pixels before ranking/placement, with a further fixed 4-pixel validity margin around incomplete semivariograms. These parameters will not be tuned against the holdout.
- **Control arms:** B19 slope percentile and seeded random separated dots at the same fold-specific budget. They are diagnostics, not extra geological candidates.
- **Placement:** shared `ced.place` at 37,654 dots and 3-pixel exclusion, masking visible catalogue pixels exactly in each holdout fold; final geometry also excludes the full known catalogue. The budget is fixed to the reported GEMSDOE32 raster count for comparability, not chosen from registry coordinates.
- **Leakage canaries:** feature-alone symmetric AUROC for every returned feature against catalogue positives vs catalogue-zero proxies; any value `>0.90` stops before placement. Passing is not proof of independence because catalogue-zero is not verified absence.
- **Holdout:** shared `vendor/gems57/spatial.folds` whole-component fixed-quadrant hide-and-recover with an 80-pixel buffer; `gems57-pooled-hide-v2`; pooled DTI with α=0.2, β=0.8, 300 m triangular kernel; 20 km spatial-cluster paired percentile bootstrap, 1,000 draws. No fold-specific fit exists for this label-free feature.
- **Registry:** check the continuous surface before any dot placement and the final dot array after placement using the shared gate. Stop at the first strict duplicate (`|Spearman ρ| >0.90` or `>70%` of final dots within 3 px of any one indexed raster). The indexed inventory is known incomplete; a pass is not a universal uniqueness certification.
- **Promotion bar:** a score must exceed the current recorded pooled holdout best `cpad_e1` **0.1981826008 HOLDOUT-DTI** on the identical evaluator/protocol, with its 95% CI reported. This is only a research comparator; no submission slot is picked. No organizer score is implied.
- **Artifact policy:** write a downloadable TIFF only after the scientific, registry, and writer checks support it. If a registry duplicate occurs, stop; do not anti-registry-place, do not call it unique, and leave `raster_sha256` null if no artifact was written.
