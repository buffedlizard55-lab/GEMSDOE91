## Scientific interpretation of the GEMSDOE32 claim

The official distance-weighted Tversky metric gives false negatives more weight than false positives, but still charges false-positive prediction mass. Predictions close to a true fault receive distance-weighted credit; multiple predictions that do not improve the maximum kernel coverage can be redundant. Thus, conditional on the reported H33-2-B2 lineage description being accurate, thinning/deleting low-marginal-credit pixels could plausibly improve the metric's credit-to-mass ratio. The sign is not guaranteed: if removed pixels cover a newly identified fault, thinning can reduce score. The current GEMSDOE32 page disclaims organizer scores, so this is a mechanistic hypothesis, not an explanation of an observed organizer score.
