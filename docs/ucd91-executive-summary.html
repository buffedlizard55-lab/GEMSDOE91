Exact submission steps (for a future gate-passing file)

  1. Download the -zeros.tif (all-finite, values in [0,1], nodata=None — this avoids the portal error “Predicted values must be in range [0, 1]”, which NaN-outside files can trigger) or the single-TIFF .zip.
  2. Open the competition → Submissions → New submission → choose the file.
  3. Paste the unique name/note from the run card (≤140 chars) into the Note field, e.g. GEMS91 UCD91 E2 TMI continuation-persistence + basement step, 48000d, HOLDOUT-DTI 0.1134 NEGATIVE not slot-ready.
  4. Only submit if the run card says ok_to_submit: true. Promotion to a weekly slot (max 3/week per rules) is a separate human selector step.

Automated gates a file must pass (no human inspection)

  • Format: single-band float32 GeoTIFF, EPSG:32611, 3730×3292, sample transform, no NaN/Inf, values in [0,1], zero mass on catalogue, dots >3 px from catalogue.
  • Science: HOLDOUT-DTI (hide-and-recover, alpha 0.2, beta 0.8, 300 m kernel) beats current best 0.206406.
  • Uniqueness: surface |ρ| ≤0.90 and ≤70% dots within 3 px of any registry raster.
  • Leakage canary: every feature alone AUC ≤0.90.

UCD91 passes format/uniqueness/canary but fails the science gate (0.113442 < 0.206406) → verdict negative.
