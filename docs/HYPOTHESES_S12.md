#### (a) Exact Official Metric Mechanics (Verified Live from [DrivenData Problem Description](https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/), 2026-10-24)
Submissions emit pixelwise fault confidence scores $p(x) \in [0, 1]$ on the $3730 \times 3292$ (`100 m`, `EPSG:32611`) GeoDAWN grid and are scored against expert-mapped faults $G$ **not contained within the existing USGS/INGENIOUS database** (Initial Prize Round: fixed private expert set; Final Prize Round: expanded verified label set) via the **Distance-Weighted Tversky Index** ($\alpha = 0.2$, $\beta = 0.8$, triangular kernel $k(d) = \max(1 - d/R, 0)$ with $R = 300\text{ m} = 3\text{ px}$):

$$\text{TP}_w = \sum_{g \in G} \max_{x:\,d(x,g)\le R} p(x)\,k(d(x,g)), \qquad \text{FP}_w = \sum_{x:\,p(x)>0} p(x)\left[1 - \max_{g \in G} k(d(x,g))\right], \qquad \text{FN}_w = |G| - \text{TP}_w$$

$$\text{DTI}(0.2, 0.8) = \frac{\text{TP}_w}{\text{TP}_w + 0.2\,\text{FP}_w + 0.8\,\text{FN}_w + \epsilon} = \frac{T}{0.2\,T + 0.2\,(S - M) + 0.8\,|G| + \epsilon}$$

where $T = \text{TP}_w$, $S = \sum_x p(x)$ is total emitted mass, and $M = \sum_{x:\,p(x)>0} p(x)\max_{g \in G} k(d(x,g))$ is proximity-credited prediction mass.
