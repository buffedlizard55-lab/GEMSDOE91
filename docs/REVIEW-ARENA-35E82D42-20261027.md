## Why GEMSDOE32's 0.2778 is plausible—and what it does not prove

The strongest supported interpretation is a **sparser/pruned member of a shared prediction family**, not a new detector independently confirmed to be superior. The exact-file audit establishes nested support relationships: the 44,090-dot D2.8 leader from GEMSDOE25 contains the 40,199-dot H27-4 support; the 37,654-dot GEMSDOE32 support is contained in the GEMSDOE36 38,854-dot raster; and the compared family exhibits extremely high 3-px overlap. This genealogy is based on raster bytes, not authorship or model provenance.

The official problem definition scores predicted pixels with a 300 m triangular distance kernel and uses a Tversky denominator that weights false negatives by 0.8 and false positives by 0.2. A sparser set that removes redundant or near-catalogue predictions can plausibly raise DTI if it sheds more false-positive mass than true-positive credit. The metric's distance tolerance also means a prediction need not be pixel-identical to an unseen trace to earn partial credit. This makes spacing and catalogue-adjacent pruning plausible explanations for the reported sequence of scores.

**Causal attribution is not identifiable from the available evidence.** Scores are unverified claims, no receipt binds them to the audited SHA-256s, and the private truth is unavailable. The byte sequence can establish which dots differ, but not which removed dots were false positives. Therefore the older numerical decomposition in [`R0_ANALYSIS_S22.md`](R0_ANALYSIS_S22.md) is a stated-model calculation, not a measured allocation of score gain. Its inferred hidden-truth totals, per-dot credit and percentage attribution must not be presented as verified facts. The official leaderboard observation recorded in the source audit is a **dated observation** (2026-10-26), not a guaranteed current value or a receipt for any focus-site file. The prompt's 0.4413 and 0.3195 claims are not silently substituted for it.

**Can a future submission exceed the reported 0.2778?** It is possible in principle, but no result in this review demonstrates that. The S22 OMTJ `HOLDOUT-DTI` is only a catalogue hide-and-recover measurement, not a calibrated public-leaderboard score; the existing evidence explicitly says that holdout has weak correlation with user-reported live scores. No leaderboard-score estimate is supplied.
