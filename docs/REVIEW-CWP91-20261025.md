1. **Dotting (+0.068)** is metric geometry: TP credits each truth pixel once (max

2. **Collar pruning (+0.0108, +0.0070)**: known-fault pixels are masked from

4. Live (USER-REPORTED) proximity lanes scored below the ≈0.052 random floor, so
   hidden faults are depleted near mapped ones — the fact CWP91 tried to encode,
   and the fact hide-and-recover structurally cannot reward (§3).

**Can we beat 0.2778?** Not demonstrably offline: no offline instrument is
