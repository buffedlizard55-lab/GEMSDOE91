## PhD-level interpretation of the 0.2778 result

The plausible explanation is an emission-economics improvement: sparse unit predictions can avoid paying the false-positive part of a mass-sensitive, saturating spatial Tversky/DTI objective for many redundant cells. A 300 m triangular kernel can award diminishing or capped benefit for multiple nearby predictions covering the same truth; deleting low-marginal-utility predictions can therefore improve the ratio even when the underlying ranking surface is unchanged. A catalogue collar can further remove predictions that have little recoverable credit under a hide-and-recover evaluation.

This is a mechanistic explanation, **not a causal conclusion** from a single reported score. The reported score alone does not establish which edit caused the gain, whether the score was organizer-confirmed, whether the same evaluation split was used, or whether the prediction surface identifies previously unknown faults. Establish causality with a matched ablation ladder (same surface, same truth, same evaluator, fixed emission budget) and establish external performance only with an organizer receipt. The repo's own historical notes describe conflicting scores/evaluators and label several fleet values as claims; that uncertainty must remain explicit. It is possible to exceed 0.2778, but the current checkout provides no evidence that the current candidate does so.
