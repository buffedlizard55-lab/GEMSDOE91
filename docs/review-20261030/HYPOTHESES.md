## 1. SGMC unit-conditioned potential-field residual break

- **Named layers:** USGS GeMS version of the State Geologic Map Compilation (SGMC) bedrock map-unit polygons (unit identity/lithology only; strip or ignore mapped fault/contact linework), paired with the already-described competition total magnetic intensity / RTP and isostatic-gravity bands after their metadata and masks are verified.
- **Physical signature / transform:** within each sufficiently represented map unit, fit a robust local background for magnetic and gravity response; compute standardized residuals and multi-scale cross-strike change points. Retain a candidate only when a residual break or truncation continues across multiple profiles and is not explained by the mapped unit boundary itself. Do not use SGMC fault traces as predictor or validation labels.
- **Why it could find uncatalogued faults:** a concealed fault can offset a contact or juxtapose units, while unit-conditioned residualization can discount the ordinary magnetic/density contrast of an unfaulted lithologic boundary. It is a structural-context test, not a geothermal-vent detector.
- **Difference from implemented repository methods:** repository searches found SGMC used as a blind off-catalogue control and in strain/control diagnostics, but no map-unit-polygon predictor or within-unit-conditioned residual-break implementation in `src/` or `scripts/`. This is the strongest implementation-novelty claim in this shortlist; it does not imply scientific originality outside this repository.
- **Named non-fault mimics:** an unfaulted intrusive or volcanic contact; a real contact displaced by map generalization; a state-compilation seam. The USGS release explicitly warns that map units are unreconciled across state borders and describes generalized bedrock mapping, so map boundaries are weak evidence under surficial cover.
- **Expected benefit / cost:** **medium potential, medium-to-high cost, high uncertainty.** Potentially suppresses contact-driven false positives while retaining structural offsets; requires polygon ingestion, rasterization, unit harmonization, robust local fitting, and a null model. No numeric DTI gain is defensible.
- **Source/access check:** USGS 2026 data-release page and NGMDB DOI landing page were fetched on 2026-10-30; the official NGMDB page exposes a GeMS GIS-data download link, and the USGS release page identifies CC0. The metadata/download link is available, but no GIS bytes, AOI clip, unit attributes, or grid coverage were acquired or tested. **Source is publicly offered; not runnable or validated in this checkout.** [USGS release](https://www.usgs.gov/data/geologic-map-schema-gems-version-state-geologic-map-compilation-sgmc-geodatabase-conterminous) · [DOI / NGMDB GIS download listing](https://doi.org/10.5066/P1A3DQZK).

## 2. Event-level earthquake migration and focal-mechanism lineation

- **Named layers:** USGS ComCat event-level origin time, hypocenter, magnitude, depth, reviewed/automatic status, and available moment-tensor or focal-mechanism solutions. Existing competition seismicity bands may be used only as a matched baseline after their identity is verified.
- **Physical signature / transform:** decluster events, estimate completeness by time and location, then find persistent, narrow, strike-coherent hypocenter clusters or swarm migration. Where focal mechanisms exist, require compatible nodal-plane orientations; otherwise lower confidence and do not infer a plane from density alone. Spatially hold out whole known fault segments and derive all fault-catalogue context from visible segments only.
- **Why it could find uncatalogued faults:** active blind structures can host aligned microseismicity or migrating swarms without a mapped surface trace. Event geometry and temporal migration add information not contained in a smoothed count alone.
- **Difference from implemented repository methods:** `B10`/`B16` dependent/independent earthquake-density bands and several static geodesy/seismic combinations are already implemented. The searched code does not implement event-level ComCat migration or focal-mechanism coherence; this candidate must be compared against those existing bands and must not be called a fresh density model.
- **Named non-fault mimics:** geothermal/volcanic swarms, quarry blasts, aftershock sequences, network changes, and catalog-completeness boundaries.
- **Expected benefit / cost:** **low-to-medium potential, medium-to-high cost, high uncertainty.** A strong active-fault signature could help locally, but most faults are not currently seismogenic and sparse focal mechanisms may leave large gaps. No numeric DTI gain is defensible.
- **Source/access check:** an official USGS FDSN ComCat query returned event records on 2026-10-30 for a broad Nevada–California bounding box and date interval. The query is intentionally broader than the missing competition footprint; it proves regional endpoint availability, not complete study-area coverage or a useful focal-mechanism count. The API response was inspected, but no event dataset was saved or ingested into the repository. [USGS ComCat API query](https://earthquake.usgs.gov/fdsnws/event/1/query?format=geojson&starttime=2020-01-01&endtime=2026-10-30&minlatitude=35&maxlatitude=42&minlongitude=-121&maxlongitude=-114&minmagnitude=2.0&limit=100&orderby=time).

## 3. Official 1 m 3DEP drainage-offset / paired-channel test

- **Named layers:** USGS 3DEP bare-earth 1 m DEM tiles for the actual footprint, with the competition DEM/slope as a 100 m context and registration check.
- **Physical signature / transform:** route channels on the 1 m terrain, detect persistent channel-direction changes and cross-channel profile breaks, and require aligned response on neighboring valleys or a paired upstream/downstream terrace/scarp. Aggregate evidence to the competition grid only after tile-level registration and masks are verified.
- **Why it could find uncatalogued faults:** young displacement may deflect or steepen channels beyond a trace omitted from a surface-fault catalogue; 1 m terrain may preserve short offsets erased by the 100 m grid.
- **Difference from implemented repository methods:** the repo contains coarse-grid drainage/scarp ideas and LiDAR-derived feature experiments, so this is **not a new method family**. The exact official 3DEP 1 m hydrologic-network / paired-channel operator was not found in `src/` or `scripts/`.
- **Named non-fault mimics:** alluvial-fan avulsion, fan-lobe boundaries, paleoshorelines, roads/culverts, differential erosion, and lithologic contacts.
- **Expected benefit / cost:** **medium potential if coverage is adequate; high acquisition and processing cost; high uncertainty.** The 1 m source can be very large and heterogeneous. No numeric DTI gain is defensible.
- **Source/access check:** USGS states that 3DEP products are free and have no use restrictions. The official products page and download tooling are available, but the specific study-area tiles, dates, completeness, and alignment were not checked. **Not viable to run until AOI coverage and rights are verified.** [USGS 3DEP products and services](https://www.usgs.gov/3d-elevation-program/about-3dep-products-services).

## 4. Repeat-season Landsat surface-temperature residuals

- **Named layers:** USGS Landsat Collection 2 Level-2 Surface Temperature scenes across seasons/years, QA/cloud masks, and local elevation, slope/aspect, land-cover, and emissivity context. Thermal rasters must not be used as fault labels.
- **Physical signature / transform:** remove the scene/date-scale thermal field and a preregistered elevation/illumination/land-cover baseline; retain only a repeatable, spatially narrow seasonal temperature residual or seasonal-amplitude break that is independently aligned with a structural indicator and recurs across usable scenes.
- **Why it could find uncatalogued faults:** shallow fluid flow or heat transport along a permeable fault can create a surface thermal expression where no mapped fault trace exists. Many blind faults will have no detectable thermal expression, so absence is not evidence against a fault.
- **Difference from implemented repository methods:** the code search found no Landsat surface-temperature scene-processing implementation. Thermal residuals have appeared in prior written hypothesis lists, so this is unimplemented but not a new written idea for the project.
- **Named non-fault mimics:** irrigation and crop cycles, playa moisture/evaporation, vegetation, emissivity changes, solar aspect, urban surfaces, and cloud/ASTER-GED gaps.
- **Expected benefit / cost:** **low-to-medium potential, high processing/confound-control cost, high uncertainty.** The fault target is not a thermal vent label; many hot or cool anomalies are unrelated to faults.
- **Source/access check:** USGS documents global scene-based Landsat Collection 2 surface-temperature products and no use restrictions. Exact scenes, cloud-free coverage, seasonal comparability, and footprint intersection were not checked or downloaded. The data product is official and generally available, but **not runnable or validated in this checkout**. [USGS Landsat Collection 2 Surface Temperature](https://www.usgs.gov/landsat-missions/landsat-collection-2-surface-temperature).
