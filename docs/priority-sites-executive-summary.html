What must pass before any TIFF is offered

  1. Explicit assigned single-method lane and preregistration.
  2. Restore and hash-check the shared template, fault catalogue, cached feature stack, and comparison rasters. Current `data/` is absent; historical manifest flags are not proof of local presence.
  3. Use shared whole-segment buffered hide-and-recover evaluator and writer; test every feature alone for leakage before trusting a model.
  4. Require a comparable, paired HOLDOUT-DTI improvement with evaluator version, withheld-positive count, and 95% CI.
  5. Check the continuous surface before placement (absolute Spearman rank correlation at most 0.90) and final dot overlap within 3 px (at most 70%) against the complete registry; stop on any breach.
  6. Re-read output and verify no NaN inside footprint, values in [0,1], and exact CRS/shape/transform. Only then show an artifact as OK TO DOWNLOAD; scientific improvement and a separate slot selector are still needed for OK TO SUBMIT.
