## Why 0.2778 led and what beating it takes (PhD-level, labelled)

**RECEIPT (bytes re-read in this repo, `evidence/forensics_f91_20261024.json`):** `h33-h33-2-b2-…-zeros` is exactly `d2.8 (44,090 dots) minus d≤2 px of catalogue → 37,654 dots`; chain `H19-5 121,131 px (0.1922 CLAIM) → 60,069 (0.2477) → 44,090 (0.2600) → 40,199 (0.2708) → 37,654 (0.2778 CLAIM)`. GEMSDOE32's own page calls that file **UNSCORED** with a 0.2747 projection — no organizer receipt exists in any checkout. Leaderboard read 2026-10-24: #1 0.4413, #50 0.2818.

**Mechanism (why thinning+pruning inflated CLAIM):** DTI numerator `TPw = Σ_g max_{j: d≤R} p_j k(d)` is a *max*, not sum, so a 3-px-wide ribbon pays 3× denominator `S-M` for 1× numerator. Thinning to 2.8 px (≈R) removes ≈pure cost (solid→dotted kept ~85% credit at 36% mass). Dots with `d(catalogue)≤2 px` spend kernel on masked truth (≈0 hidden credit; nested-pair MODEL gives |G|≈14–15k, credit/dot 0.139 vs break-even α·DTI=0.0556). The 2,171 retained flank dots at 2–3 px are plausible splay/stepover positions — why the file kept them.

**What beating it requires (MODEL arithmetic):** at 37,654 dots and |G|≈14k, DTI 0.32 needs credit/dot ≈0.160 (+15% over R0), DTI 0.4413 needs ≈0.220 (+58%). Emission tuning on the same H19 surface is exhausted (fleet sweep: solid→dotted was the large jump; later edits ≤0.015). Detector ranking must improve — the surface's top-ranked 37k pixels must contain more hidden-fault kernel credit. Holdout is not live score, but credit density on hide-and-recover catalogue faults is the only measurable proxy for ranking quality.

**PhD judgement:** The most plausible ranking gain is to add an *active* view that the H19 topo-magnetic lineage largely ignored. USGS/INGENIOUS catalogue is exposure-biased to Pleistocene scarps; blind Holocene faults under Quaternary cover lack scarps but retain seismicity, decadal strain, and K-alteration. A detector that fires only where seismic lineaments, transtensional strain, and radiometric edges *coincide* with traditional potential-field basement steps should raise credit density while rejecting single-physics mimics (volcanic contacts, terrace bluffs, playas). FUSE raised same-instrument credit/dot +17.4% with complementary views; SSHAC targets a comparable orthogonal view (active vs static).

## Frozen experiment plan (budget exactly 3, protocol §6)

**Instrument (identical across E1–E3):** `evaluate_holdout.build_segment_buffered_folds` whole-component with `bridge_px=3`, `buffer_px=10`, 4 quadrants NW/NE/SW/SE, 60,988 total withheld positives (distribution by fold recorded), visibility/bias re-derived from *visible* faults only, `alpha=0.2 beta=0.8 R=300 m` pooled DTI via `scripts/dti.py`, spatial block-bootstrap 5 km tiles for 95% CI. Emission: greedy spaced 2.8 px, 37,654-dot budget split by fold footprint share, candidates >3 px from visible catalogue (holdout) / >3 px from full catalogue (final build), unit mass {0,1}, deterministic stable argsort tie-break. HGB hyperparameters verbatim from `build_denovo._train_hgb` (300 iters, lr 0.06, 63 leaves, min-leaf 40, L2 1.0, seed 20261024). No distance-to-catalogue feature.

- **E1 SS-HAC-HGB (lane):** 32 features = 19 raw footprint percentiles (B1–B19 via `fill_footprint_percentile`) + 3 family high-pass ridges (mag/grav/topo as in denovo) + 10 new seismic-strain-radiometric derived features defined in `src/gems91/ss_hac.py`. Sharp surface, >3 px exclusion.
- **E2 SS-HAC-scatter (emission test):** *same trained E1 models*, surface Gaussian-smoothed σ=1.85 px (`fuse91.scatter_smooth`) before identical emission — tests GEMSDOE32 Monte-Carlo finding that 1.85 px localization scatter favours smooth cover under `|G|≈14k` truth. Holdout-conservative rule: E2 is selected only if it beats E1 on pooled HOLDOUT-DTI.
- **E3 SS-HAC-ring (collar geometry test):** winner of (E1,E2) plus tiered greedy emission allowing 2<`d(cat)`≤3 px collar ring capped at 6% of each fold's budget (`fuse91.tiered_greedy_spaced`), otherwise identical. Tests whether R0's 2,171 flank dots at 200–300 m carry generalisable signal vs being inherited halo. Ring is re-derived from *visible* catalogue only in holdout, so cannot leak.

**Selection rule (frozen before any SSHAC number):** final build uses the arm with the highest pooled HOLDOUT-DTI among E1–E3 provided it beats the comparable prior best on the *same instrument* (HGB-CTX 0.142885 on build_denovo checkerboard vs S11-MHTR 0.206406 on hide-recover; both reported, SSHAC's instrument is hide-recover so S11 is the comparable). Promotion requires: beats S11-MHTR 0.206406, leakage canary `max symmetric AUC ≤0.90` for all 32 features, pre-placement surface `|ρ|≤0.90` vs every indexed registry raster, final-dot directed overlap `≤70%` vs every *real* registry raster (lattice calibrator reported separately), and all format validators PASS on exact written bytes. Otherwise verdict is negative / research-only. No holdout number is an organizer score.

**Controls (same folds, not experiments):** seeded random spaced dots at matched count (instrument-identity check, should reproduce DENOVO receipt 0.070827 on checkerboard if instrument matched; on hide-recover its value is reported but not subtracted), and SGMC off-catalogue control (REPORT ONLY, `derived_sgmc_faults_100m_u8`, USGS DS-1052).
