What the session learned

PU gradient boosting on the 19 official bands lands its dots in the same 15–25% of the footprint every time. Eleven earlier lanes overlap this file by more than 70%. A new file therefore needs a genuinely new information source, not another model on the same stack. Live evidence also shows that new faults are depleted near mapped faults: proximity lanes scored below uniform random, and dots 1–2 px from the catalogue earned about zero. Hide-and-recover splits put 55% of hidden truth within 1 km of visible faults, so they over-reward proximity. See the executive summary and the preregistration and results.
