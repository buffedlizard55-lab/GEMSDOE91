What is required before a TIFF can appear here

  2. Run the shared buffered whole-segment hide-and-recover evaluator. Recompute catalogue-based features from visible faults per fold, mask visible faults pixel-exactly, pool DTI components, and record evaluator version, withheld positives, and 95% CI.
