Continue only when the separate scientific/uniqueness gates and selector explicitly approve the exact SHA-256 and assign an available weekly slot; that approval does not exist for this file.

It is single-band float32, EPSG:32611, 3730×3292, transform (100, 0, 243350, 0, −100, 4508550), with every cell finite in [0, 1] and 0 outside the footprint. This avoids the portal error “Predicted values must be in range [0, 1]”; raw −3.4e38 sentinels and NaN twins are known format risks, but the exact cause of the user’s failed upload has not been verified. Never upload an audit JSON, a NaN twin or a catalogue file.

  4. Upload. Use the official submissions page. Paste the recorded name and the note (140 characters or fewer) from the front page.
  5. Record the receipt. Copy the public score from the submission page into the ledger as ORGANIZER-CONFIRMED. Until then, no score exists for the file.
