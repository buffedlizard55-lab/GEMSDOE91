1

2

3

Run one preregistered method lane

Use the cached stack plus shared scripts/evaluate_holdout.py and scripts/submission_writer.py. Test each feature alone; AUC > 0.90 is a leakage canary until explained.

4

Stop on duplication or a failed gate

Check both the pre-placement surface and final dots against the available registry. Stop and log a duplicate if surface rank correlation exceeds 0.90 or more than 70% of dots fall within 3 px of a registry raster. Run the shared validator and record SHA-256, evaluator version, withheld positives and 95% CI in a JSON run card.
