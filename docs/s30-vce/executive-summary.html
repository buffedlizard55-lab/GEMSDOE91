The mechanism, from the metric algebra

The official metric (DrivenData problem description, §Performance metric) is the distance-weighted Tversky index DTI = TP_w / (TP_w + 0.2·FP_w + 0.8·FN_w + ε) with a triangular kernel of 300 m (3 px) support. For binary dots this simplifies to a pure coverage-per-mass trade: a dot within 3 px of a true fault pixel earns kernel credit; a dot beyond 3 px contributes only to FP_w (penalty 0.2 per unit mass). So:

  • Dots must be sparse and spaced (~2.8–3 px apart): two dots closer than the kernel radius double-pay mass for one unit of coverage.
  • Dots must avoid the mapped catalogue: the test labels are faults not in the catalogue, so catalogue-hugging dots burn mass near zero-credit truth. The winner has only 5.8% of dots within 3 px of the catalogue (median 19.7 px away) — the most "off-catalogue" member of the family.
  • The budget (37,654 dots) is near the family optimum: more dots (60k–121k) monotonically lost score because extra mass outran the extra coverage; the family sweep above is direct evidence.
  • The all-finite zeros encoding is what the winner shipped (-zeros), and it is what the form accepts.

Cross-check: this repo's pinned byte-identical copy of the winner raster (data/registry/GEMSDOE32__h33-2-b2-zeros.tif) reproduces every number in the table above from its own pixels. The nine pairwise overlaps (88–100%) were recomputed here on 2026-10-31 (receipt), not copied.

3 · Can we generate a submission that scores higher than 0.2778?

Answer (PhD-level, evidence-graded):

  1. Not by repeating the winner family. All nine leaders are ≥88% duplicate in dot space; the family's score ladder is exhausted at 37,654 dots, and any resubmission of a family member spends a weekly slot for zero information.
  2. Not with today's vent-lane candidate on the initial private labels. The blind independent diagnostic agrees: on USGS SGMC faults strictly off the catalogue (62,122 positives, the best public proxy for "faults missing from the catalogue"), S30-VCE scores SGMC-OFFCAT-DTI 0.048 vs the champion's 0.095. The ridge family is genuinely better at covering catalogue-like hidden faults.
  3. Yes — plausibly — through the Final Prize Round mechanism, which the duplicates cannot use. The official rules (problem description) state that after the Initial Prize Round an expert panel converts submitted predictions into new verified labels, and every submission is re-scored against the expanded set. A duplicate of the champion family can never contribute a new label (its dots are already known). A unique, physically-defensible, vent-concordant raster is exactly the kind of discovery artifact experts can verify — and each verified fault it flagged becomes scoring truth for it. That is the only mechanism in this competition by which a new entrant can exceed the incumbent family's expected value, and it is why this repo generated a genuinely unique file instead of cloning 0.2778.
  4. Also yes — by supervised lineament models measured on the repo's hide-and-recover instrument (S27-OSDR HOLDOUT-DTI 0.1595 [0.1393, 0.1797] on the same evaluator; GEMSDOE32's own H51-EXP2 claims +65.7% over champion on their instrument). These are catalogue-recovery numbers, not leaderboard receipts — but they say the ridge family is not optimal even at its own game. The next session should port the S27-OSDR emission into a drift-checked unique placement (see ranked hypotheses).

  • Protocol verdict: NEGATIVE (do not auto-spend a weekly slot). E2 did not beat its matched negative control on the holdout (paired CI includes 0), and the S27-OSDR repo best (0.1595, same instrument) is far above. Promotion to a live slot is a separate selector step — that selector is you.
So what should you actually submit? Three defensible choices, in order of P(win): (a) If a weekly slot is precious and you optimize only the Initial Prize Round: save the slot — no unique file in the fleet is evidence-backed to beat the incumbent family's expected score. (b) If you can enter a file and want Final-Prize-Round exposure (expert-verified discoveries become labels, which duplicates can never earn): submit S30-VCE E2 — it is unique, form-safe, and built on verifiable geothermal-vent science (the competition's stated target is faults indicative of geothermal resources). (c) Run the next lane (H-VCE-2: supervised lineament × vent concordance) first — its holdout target is ≥ 0.16 — and submit only if it clears it.

5 · How to make a submission (exact steps)

  1. Download the GeoTIFF above (or the .zip containing exactly that one TIFF).
  2. Open the competition submission page: drivendata.org/competitions/306/competition-doe-gems/submissions/ (sign in required).
  3. Click “File to submit” and choose the .tif (or .zip). Do not upload an HTML page, an audit JSON, or a -nan variant — those trigger “Predicted values must be in range [0, 1]”.
  4. Paste the note: S30 VCE vent-concordant emission 37654d; GDR vents+alteration+strain; see run-card
  5. Submit. The file is single-band float32, all values in [0, 1], NaN-free, CRS EPSG:32611, 3730×3292, geotransform identical to the official sample — the form accepts it.
