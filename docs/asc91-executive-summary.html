Step 6 — After scoring, record the receipt

Copy the organiser score from the submission page into ledger/submissions.csv as ORGANIZER-CONFIRMED with the date. Until that exists, no number for any file here is a leaderboard score — holdout numbers stay labelled HOLDOUT-DTI.

The “Predicted values must be in range [0, 1]” error — cause and prevention

That portal rejection is triggered by values outside [0, 1], which in practice means NaN or sentinel fills (e.g. −3.4×10³⁸) or an unstated nodata in some earlier fleet twin. This session's file eliminates the entire class: the fail-closed template writer refuses non-finite or out-of-range arrays before writing, and the written bytes were re-read and verified cell-by-cell (finite everywhere; min 0.0, max 1.0; no nodata tag). If a future file ever triggers the error, do not “fix” it by clipping — rebuild it through the writer and re-check the run card.

What would change the verdict?

  • A new lane (preregistered: step×context fusion) beats 0.142885 pooled HOLDOUT-DTI on this identical instrument, ideally confirmed on the second holdout instrument.
  • Both novelty phases pass against an enumerated registry including this file.
  • A selector verifies the live weekly allowance and picks the slot. That step is deliberately separate from building files.
