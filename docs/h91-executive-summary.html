Process for a future, separately cleared candidate

  1. Read the current project README and the assigned method paragraph. If no single lane is recorded, do not launch an experiment.
  2. Use the pinned shared feature stack, holdout evaluator, spatial-fold utilities, and submission writer. Test each feature alone; any AUC above 0.90 is leakage until proven otherwise.
  3. Hide whole fault components, buffer training from withheld segments, mask visible catalogue pixels exactly, and compute pooled HOLDOUT-DTI with the specified 300 m triangular kernel. Record evaluator, withheld-positive count, and 95% CI.
  4. Run the literal registry checks on the continuous surface and the final candidate dots using a complete, hash-verified inventory. Stop on rank correlation >0.90 or directed 3-pixel dot overlap >70%; an incomplete scan is not a pass.
  5. Re-read the written TIFF and ZIP; check the exact sample grid, one float32 band, finite [0,1] values and catalogue/footprint constraints. Format validity is not science or organizer acceptance.
  6. Use a file only if the current run card explicitly says OK TO SUBMIT, every automated gate is true, and a separate selector receipt confirms current allowance. Verify the file SHA-256 before any account action.
  7. After an actual organizer receipt, label its score ORGANIZER-CONFIRMED and retain the receipt, date, and file hash. Never present a projection as a score.
