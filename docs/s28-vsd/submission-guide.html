Why the earlier “[0, 1]” error happened

Some historical downloads encode the outside-footprint collar as NaN (the competition sample's own nodata convention). DrivenData's validator reads the raw band and rejects any non-finite value. The shared writer therefore emits the zeros encoding: finite 0.0 outside the footprint, 37,654 dots at 1.0, everything inside [0, 1] — verified here by an independent re-read before publication. If a portal error ever appears again, check gdalinfo Min/Max first; this repo's validator replicates the portal's checks.
