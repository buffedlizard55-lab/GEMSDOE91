Executive summary: exactly how a submission happens

Competition: DrivenData DOE GEMS #306, problem page. The target is geological faults, including faults missing from the public USGS set. Submit one single-band float32 GeoTIFF in EPSG:32611, 100 m, same bounds as the sample, values in [0, 1]. The official page says data outside the bounds should be null or NaN. This project’s downloadable file is all-finite, with zeros outside the footprint and no nodata tag, because a prior upload returned “Predicted values must be in range [0, 1]” and a negative nodata sentinel is one measured cause of that message. Organizer acceptance of zeros versus null outside the footprint is not receipted here. Do not upload this guide, a JSON file, or a training raster.

Why the reported 0.2778 is not a recipe

Fetched 2026-10-25 from the GEMSDOE32 page: h33-h33-2-b2 is described as a 0.2708 base with every dot at d(catalogue) ≤ 2 px deleted (37,654 dots). That page says no organiser score exists, and its own note calls 0.2747 a projection and the file UNSCORED. The user-reported 0.2778 is not a receipt.

Local geometry of the pinned zeros twin (SHA-256 c55bafc470054e8271dcb89347a17e07fefe50de6af6e6ba6c4b169ef7ab6fa9): 37,654 unit dots, 0 within 2 px of the catalogue, median nearest-neighbour spacing 3 px. Under the published metric, DTI = TP / (TP + 0.2·FP + 0.8·FN), triangular kernel, R = 300 m. Mass on mapped faults cannot earn credit if the test faults are absent from that catalogue, and it still pays the false-positive term. Deleting it can raise DTI if matched credit is kept. That mechanism is sound. It does not prove this file scored 0.2778, and copying the file is forbidden by the uniqueness rule.

The public leaderboard, fetched 2026-10-25 from DrivenData, shows rank 1 at 0.4413. The prompt’s 0.3195 is below many current public rows. Neither number is a receipt for a file in this repository. Beating 0.2778 on the organizer metric is possible in principle because the public board is already higher. This experiment does not do it.
