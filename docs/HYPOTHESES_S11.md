## 1. PhD Forensic Analysis of `GEMSDOE32` (`0.2778`), Public Leaderboard (`0.4413`), and Two Newly Discovered Feature-Stack Irregularities

### 1.1 Why and How `GEMSDOE32` (`h33-h33-2-b2-20261004T220000Z-e5eb6e7e-zeros: 0.2778`) Scored Highest in the Historical Fleet
Under the official [DrivenData Problem Description](https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/) (verified via direct page fetch on 2026-10-24), predictions $p(x) \in [0, 1]$ are evaluated against newly identified faults $G$ using the **Distance-Weighted Tversky Index** ($\alpha = 0.2$, $\beta = 0.8$, linear triangular kernel $k(d) = \max(1 - d/R, 0)$ with support $R = 300\text{ m} = 3\text{ pixels}$ at $100\text{ m}$ resolution):

$$\text{DTI}(\alpha, \beta) = \frac{\text{TP}_w}{\text{TP}_w + \alpha\,\text{FP}_w + \beta\,\text{FN}_w + \epsilon} = \frac{T}{0.2\,T + 0.2\,(S - M) + 0.8\,|G|}$$

where:
- $T = \text{TP}_w = \sum_{g \in G} \max_{x:\,d(x,g)\le R} p(x)\,k(d(x,g))$ is the distance-weighted true positive count,
- $S = \sum_{x} p(x)$ is total emitted prediction mass,
- $M = \sum_{x:\,p(x)>0} p(x) \max_{g \in G} k(d(x,g))$ is proximity-credited prediction mass, so $\text{FP}_w = S - M$, and
- $\text{FN}_w = |G| - T$ (using $\alpha + \beta = 1.0 \implies \text{TP}_w + 0.8\,\text{FN}_w = 0.2\,T + 0.8\,|G|$).

Forensic byte-level verification (`docs/parent-forensics.json`) and direct inspection of the [GEMSDOE32 portal](https://buffedlizard55-lab.github.io/GEMSDOE32/docs/index.html) (fetched 2026-10-24; note that `GEMSDOE32` explicitly states *"NO ORGANISER SCORE EXISTS for this or any artifact in this repository"*, so `0.2778` is a user-reported benchmark `CLAIM` unless backed by a submission-page receipt) establish the four exact mathematical operations that produced `R0` (`37,654` binary unit-mass dots):

2. **2-D Poisson-Disk Thinning (`GEMSDOE24` $d \ge 1.5\text{ px} \to 0.2477$; `GEMSDOE25` $d \ge 2.8\text{ px}$, `44,090` dots $\to 0.2600$ user-reported):** Because $T$ takes the **pointwise maximum** $\max_{x:\,d(x,g)\le 3} p(x)\,k(d(x,g))$ rather than the sum, a 3-pixel-wide ribbon contributes $1\times$ to $T$ and $3\times$ to $S$. Thinning to $d \ge 2.8\text{ px}$ ($280\text{ m} \approx R$) eliminated redundant $(S - M)$ false-positive mass (`+0.0678`).
3. **Isolated 0-D Speckle Pruning (`GEMSDOE28` `solo`, `40,199` dots $\to 0.2708$ user-reported):** Removed `3,891` isolated points lacking collinear neighbors within $900\text{ m}$ (`+0.0108`).
