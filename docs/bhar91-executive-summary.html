How the "Predicted values must be in range [0, 1]" Error Is Permanently Prevented

1. Single-Pass Sentinel Scrubbing (-3.4028235e+38)

Raw GeoDAWN / training feature bands contain float32 nodata sentinels (-3.4028235e+38) on 1,521–3,061 cells inside the active submission footprint. Every band is scrubbed via isfinite(arr) & (arr > -1e30) and interpolated by nearest-valid Euclidean distance transform before any gradient, curvature, or model evaluation.

2. All-Finite nodata=None Zero-Padded GeoTIFF Encoding

Portal validators that check 0.0 ≤ x ≤ 1.0 across the raw array buffer before masking nodata=NaN reject rasters containing outside-footprint NaN cells.
