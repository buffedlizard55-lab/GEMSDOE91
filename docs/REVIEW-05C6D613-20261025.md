## Experiment protocol and reproducibility

- **Preregistration:** [HYPOTHESES_05C6D613.md](HYPOTHESES_05C6D613.md), SHA-256 frozen at run start: `b9c3bc0a4b9e41162c1e56011c80d5af9013f52993805c5d7dfad3449d113d55`.
- **Input rasters:** manifest-pinned `sample_submission.tif` (`sha256 2176d08e…d35cbc`), `existing_faults.tif` (`7ba308cc…e4093`), and 19-band GeoDAWN stack (`4371c82e…3123bc5`). The stack was restored from the existing project mirror and byte/hash verified. B12 is `det_elev`; B19 is `det_elev_slope`. The feature code accepts no catalogue or label argument.
- **Fixed candidate:** local semivariograms at lags 1/2/4 pixels, 11×11 window, averaged horizontal/vertical increments with ≥50% valid pairs; Hurst-like exponent is half the OLS slope of log semivariance versus log lag. Score is the Gaussian-gradient magnitude of the exponent (sigma 2 px), with fixed edge/validity erosion. B19 is only a slope-control arm.
- **Shared holdout:** `vendor/gems57/spatial.folds` and `vendor/gems57/evaluate_holdout.py` (`gems57-pooled-hide-v2`), not a private scorer. Four fixed label-blind quadrants; whole intersecting 8-connected components withheld; 80-pixel buffer; visible catalogue masked pixel-exactly during placement/evaluation. The label-free candidate is not trained on held labels. DTI uses α=0.2, β=0.8 and a 300 m triangular kernel. Pooled 95% CI uses 20 km spatial clusters and 1,000 paired bootstrap draws.
- **Canaries:** all four returned feature fields tested individually; maximum symmetric feature-alone AUC was `0.5577300102310019` (LEAKAGE-CANARY-AUC, not DTI). Catalogue-zero cells are proxy negatives, so passing is not proof of no leakage.
- **Registry:** pre-placement surface check ran before any dot placement; final dot check used the final deterministic mask. The shared gate stopped at the first duplicate. Three missing files and non-universal scope are explicitly retained; no complete fleet-wide claim is made.
- **No output:** because final dots were a duplicate, `submission_writer.py` was not called and no GeoTIFF/ZIP was created. The dot-mask digest is not a raster SHA. The existing OLC91 current-run pointer was left unchanged.
