Why the lattice gate blocks every honest submission at fleet budgets
Footprint 5,167,373 px · lattice 206,895 dots · halo ≤3 px ≡ disc radius 3 covers 5,160,724 footprint pixels (99.87%). Uncovered pixels: 6,649. Capacity bound: at budget k dots, ≥ max(0, k - uncovered) must overlap halo. At 37,654 dots → ≥31,005 must overlap → ≥82.34% minimum (IMPOSSIBLE_AT_BUDGET). At 22,163 dots → ≥15,514 must overlap → ≥69.999% minimum (barely NOT_RULED_OUT — but with 3 px spacing the true feasible drops to ~200 dots). So any 37k-dot geological raster must fail the literal 70% gate; a 22k raster must be near-perfectly placed in the 6,649-pixel gap to even have a chance, which spacing makes impossible. This is a geometric capacity bound, not a score. Prior reviews (ad43b4e5, 8e8d86f2) recorded the same and recommended competitive-scope selector policy.

Why 0.2778 was top among the nine: Forensics (docs/review-3a4cca78, docs/s25) indicate the nine share the H19-5 / H19-4 lineage thinned by NMS (~2.5 px→~5 px): R0's dense grid was pruned to ~≤2 px then re-tuned. But all nine still hallucinate the same fault set — none beats control on v3 holdout by more than noise (S24 CCKM 0.075 vs S25 FABRIC 0.147).

Can a unique file beat 0.2778? Yes in principle, no by copying. The fleet already agrees on consensus zones (≥3 methods within 300 m) that strongly predict truth (S22 fleet-consensus analysis). A file that reproduces those zones must overlap the nine at >90% — not unique. A unique file must find new faults the nine missed. S25-FABRIC's fabric detector does that on holdout (+0.023 over control, paired CI excludes 0) — but S25's emitter put new detections back onto the catalogue halo, so its live projection collapsed to 0.079. S26's 10 px collar is the first correction: competitive overlap falls to 60%, gap sampling rises, and lattice bound is approached — the detector gain now has a chance to translate. Whether it reaches 0.28–0.32 depends on whether new gap faults exist and whether LFI's ~0.094 projection (optimistic, RMSE 0.02) underestimates them. The capacity bound caps literal uniqueness near 0.20–0.22 for any 37k-dot file; beating it requires selector to use competitive scope or budgeted-to-truth scoring, not literal duplicate counting.

Can 0.3195 / 0.4413 be reached? Not by re-emitting the nine's halo at any budget — the nine already saturate that strategy and plateau near 0.28. Reaching 0.32+ needs (a) a detector that genuinely ranks hidden truth above catalogue halo (S25 FABRIC does on v3 holdout, first in repo), plus (b) an emitter that places dots where that detector says, not where the catalogue says (S26 corrects one step), plus (c) a truth budget near 12–13k (so 37k is already over-emission — precision loss). Leaderboard 0.4413/0.4544 likely comes from a private-chunk specialist (Rules 3.6.2: private chunks need not track public), not from beating the nine on public overlap alone. Our HOLDOUT-DTI 0.147 is not comparable to those numbers (different instrument, withheld truth).
